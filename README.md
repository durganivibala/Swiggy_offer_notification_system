# 🏏 IPL Six Alert Notification System (Swiggy Offer Bot)

A **real-time WhatsApp chatbot notification system** that alerts users whenever a **SIX** is hit in an IPL match, helping them instantly avail time-limited offers (like Swiggy’s 66% off for 6 minutes 🚀).

The system:
- Sends a **WhatsApp poll** before every IPL match (7:30 PM)
- Starts monitoring only if the user replies **START**
- Sends instant WhatsApp alerts whenever a **six** is hit
- Allows the user to **STOP** notifications anytime

---

## ✨ Features

- 📅 **Daily Match Poll at 7:30 PM**
- 💬 **WhatsApp chatbot-style poll** using Twilio
- 🏏 **Live IPL match detection** from Cricbuzz
- 🔔 **Real-time SIX detection**
- ▶️ **START / STOP controls** for the user
